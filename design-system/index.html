Result card states

Seven states pair clear text with icons. Scores are placeholders, not probabilities.

  • No result yet

    Enter all nine readings to see the model score.

  • Checking these readings…

    The result will appear here.

  • Low

    Model score 20 of 100. This is not a probability.

    These readings resemble the model's running examples more than its failed examples. This does not mean the pump is healthy.

  • Elevated

    Model score 64 of 100. This is not a probability.

    These readings sit between the model's running and failed examples.

  • High

    Model score 85 of 100. This is not a probability.

    These readings resemble the model's failed examples more than its running examples.

  • Outside training data range

    Intake pressure is outside the mock training data range. This is not an equipment limit.

  • Can’t check these readings

    Enter a valid value in each marked field, then try again.
